Security Architecture

Security Features

🔐

AES-128 Encryption

All passwords encrypted using AES/ECB/PKCS5 before storing in MySQL. Never stored in plain text.

🧩

SQL Injection Prevention

Every DB query uses PreparedStatement with parameter binding — no raw SQL concatenation.

🔑

Session Authentication

Server-side sessions store member_id/admin_user. Every protected page validates session first.

🚫

Unauthorized Access Block

Direct URL access to protected pages redirects automatically to the appropriate login page.

✅

Dual-Side Validation

Forms validated on both client (JavaScript) and server (Java) for complete protection.

📧

Gmail App Password

SMTP uses a revocable Google App Password — separate from the main account.
